# Odin Pro в админке паков

Odin Pro / Premiere Basics добавлен только в реестр `packages_authors`.
Главная, публичное меню Authors и `marketplace_items` этот реестр не используют.
Привязка к товарам Motionflow для Odin скрыта. Вкладка Users подключается
к защищённому API сайта Odin и показывает его аккаунты, подписки и CEP-устройства.
Настройка, миграция, подготовка паков и порядок включения описаны в
[плане интеграции](./odin-integration-runbook.md).

После запуска обновлённого приложения откройте **Profile → Packages → Premiere
Basics — Odin Pro**. Автор создаётся при первом чтении реестра; отдельная
SQL-миграция не требуется. Внутренний ID `900000001`, slug `odin` — это ID
реестра паков, а не пользователя или продавца Motionflow. Конфликт ID/slug
останавливает создание, существующие настройки автора не перезаписываются.

## Хранение и загрузка

- Бакет по умолчанию: `odin-pro` (существующий бакет сервера Odin).
- Фактически настроенный бакет после подготовки 30 сентября 2026: `motionflow-odin`;
  проекты AE `11` и PR `12` скрыты до проверки в Adobe.
- Изменить бакет можно в **Packages → Authors**.
- ZIP загружается по существующей схеме
  `secure/packages/900000001/{projectId}/{filename}.zip`.
- Прямая загрузка ZIP через веб ограничена существующим лимитом 4 MB.
  Большие архивы загрузите через R2Sync и выберите **Bind from R2** в редакторе.
- R2Sync получает Odin через `/api/r2sync/authors`, параметр автора — `odin`.
- Превью загружаются в публичный бакет Motionflow по существующей схеме
  `public/downloads/packages/900000001/{projectId}/preview-*`.
- Для чтения структуры и диффов в корне бакета нужна распакованная папка с basename ZIP
  без `.zip`, с `manifest.json` и файлами пакета. Сам upload ZIP не
  распаковывает архив — это существующее поведение.
- `.odin` содержит обычный JSON (`settings` и `content` / `contents` /
  `structure`); поддерживается UTF-8 BOM. Бинарного декодера нет.

Используются R2-настройки `next-app`. Ключ должен иметь доступ к выбранному бакету Odin и
публичному бакету для превью. Настройки доступа к админке прежние:
`PACKAGES_ADMIN_EMAILS` и секрет R2Sync. Содержимое бакета Odin не добавляется
в разрешённые источники публичной витрины Motionflow.

Подключение каталога к `odin-pro.com` подготовлено за выключенным по умолчанию
флагом `MOTIONFLOW_CATALOG_ENABLED`. Публикация `odin.zxp` / `latest.json` — отдельный шаг;
создание автора не переключает работающую панель на новый каталог.

Проверка без базы и R2: `node --test scripts/test-odin-packages.mjs`.
