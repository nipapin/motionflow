# Odin: подключённые пакеты, 1 октября 2026

Рабочий `odin-pro.com` использует каталог Motionflow. Автор `900000001` хранит
четыре ZIP и соответствующие распакованные папки в приватном `motionflow-odin`.
Во всех папках используются `Assets`, `Previews`, `Fonts` и plaintext JSON `.odin`.

| Host | Edition | CEP ID | Motionflow project | ZIP / folder stem |
| --- | --- | --- | --- | --- |
| AE | Full 1.2.0 | 283 | 11 | odin-pro-ae |
| PR | Full 1.2.0 | 275 | 12 | odin-pro-pr |
| AE | DEMO | 900000003 | 13 | odin-pro-ae-free |
| PR | DEMO | 900000004 | 14 | odin-pro-pr-free |

Все четыре проекта имеют `visible=1`, `admin_only=0`. Архивы лежат в корне бакета,
например `odin-pro-pr.zip`; структура читается из `odin-pro-pr/manifest.json`.
Старые ID полных паков сохранены. ID Demo закреплены отдельно от полных паков.
PR Demo хранит дерево в `settings.contents`: сайт и панель поддерживают этот
экспорт наряду с верхнеуровневыми `contents`, `content` и `structure`.

Рабочая карта `ODIN_CATALOG_PACK_MAP`:
`{"275":12,"283":11,"900000003":13,"900000004":14}`.
На Odin включён `MOTIONFLOW_CATALOG_ENABLED=true`; соединение идёт через
`http://127.0.0.1:3000`. Разрешённый download host:
`motionflow-odin.4dd38e93681ae447cac2c65dca9aef09.r2.cloudflarestorage.com`.
Вход и проверка подписки остаются на стороне Odin. Подписчик получает Full;
авторизованный бесплатный аккаунт может скачать только точный Demo-архив.

## Панель

После входа автоматически устанавливается версия для текущего Adobe host и
подписки. Имеющаяся актуальная версия активируется без повторной загрузки.
При смене подписки выбирается другая версия; загрузка предыдущей отменяется,
её позднее завершение не открывает прежнюю библиотеку. До готовности нужного
пака библиотека недоступна, отображается полноэкранный прогресс без закрытия,
сворачивания или пользовательской отмены. При ошибке доступен Retry setup.

Подписка проверяется при входе, возвращении фокуса, каждые 60 секунд и через
секунду после известной даты истечения. Переключение основано на ответе сервера;
ошибка связи не считается окончанием подписки. Новые установки используют
каталог `_ABS` рядом с preferences Odin, если пользователь ещё не выбрал путь.
Существующий пользовательский путь сохраняется. Dev-паки удалены из конфигурации
Odin; development использует тот же авторизованный Full/Demo flow.

## Следующая задача: превью и источники паков

По запросу пользователя 1 октября 2026 эту часть пока не менять.
Превью пака в панели должно приходить из каталога Motionflow и нашего R2.
Нужно убрать legacy fallback `api.get-atomx.com` из конфигурации Odin и профиля,
когда превью проектов будут заполнены и проверены в Motionflow.

В `next-app` добавление паков автора нужно ограничить объектами нашего R2:
проверять принадлежность выбранного бакета/ключа, не принимать внешние источники
паков и произвольные download URL. Для превью использовать штатное хранение
Motionflow и передавать его через `previewUrl` → `image_url` в каталог Odin.
Это запланированное изменение: текущая логика источников и fallback превью
в этом шаге сохранена.

## Проверено

- R2 folder inventory и размер каждого файла совпадают с manifest для всех паков.
- ZIP inventory, встроенные JSON и manifest совпадают с распакованными папками.
- Реальный CEP resolver находит ресурсы всех элементов: AE Full 968, PR Full 963,
  обе Demo по 51; отсутствующих и неподдерживаемых ресурсов нет.
- Рабочий каталог выдаёт четыре ID; все подписанные URL читают настоящие ZIP.
- Проверен серверный адаптер Odin для AE/PR и обоих состояний подписки.
- Публичный и локальный CEP API возвращают 401 без авторизации.
- Прошли 18 тестов панели Odin, 10 тестов Motionflow и 17 тестов Odin backend,
  проверка изоляции брендов, TypeScript и production-сборки сайта и панели Odin.

Применение ресурсов и первый вход с установкой внутри Adobe требуют ручной
проверки в Adobe. ZXP и latest.json этим подключением не публиковались.

## Повторяемые команды

`node scripts/inspect-odin-releases.mjs` проверяет R2 и ZIP без изменений.
`node scripts/connect-odin-releases.mjs` показывает план привязки;
`--apply --env-file=.env` повторяет привязку, сохраняет ID и создаёт резервную копию.
Этот скрипт сам не переключает флаг на Odin и не перезапускает сайты.
`node scripts/check-odin-integration.mjs` проверяет чтение зарегистрированных структур.

На сервере сохранены резервные копии сборки Motionflow и env Odin в
`next.motionflow.pro/.cache/odin-connect-20261001`, метаданных проектов и env
Motionflow — в `.cache/odin-connect-2026-10-01T14-20-43-604Z`.
При откате сначала выключить каталог на Odin и перезапустить только `odin-pro`;
затем при необходимости восстановить сохранённые настройки и сборку Motionflow.
